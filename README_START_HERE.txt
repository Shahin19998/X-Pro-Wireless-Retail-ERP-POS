XPRO STORE POS v0.4 — DEVELOPMENT BUILD

Windows setup:
1. Extract the ZIP to a permanent folder (not directly on the USB).
2. Install Python 3.10+ from python.org, enabling Add Python to PATH.
3. Double-click START_XPRO.bat.
4. On first run, create the administrator account.
5. Use sample transactions only until validated.

This version stores local SQLite data in the extracted app folder. Back up the database regularly.
Receipt HTML opens in your browser. Duplex printing must be selected in the printer dialog; there is no direct printer driver integration yet.
Cash drawer hardware is not activated. Payment-card processing and real money-transfer/lottery terminals are NOT integrated.

New in v0.4: snapshots of policy text saved with each sale, non-overwriting receipt archive, and admin review for non-merchandise discretionary returns.

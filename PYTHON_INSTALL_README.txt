XPRO STORE POS - PYTHON INSTALLATION

1. Copy the ZIP from USB to your Windows computer.
2. Extract ALL files into a permanent folder.
3. Double-click INSTALL_PYTHON_AND_START.bat.
4. If Python 3.10+ is already installed with Tkinter, the app launches.
5. If Python is missing, the setup downloads the official Python 3.12.10 64-bit installer from python.org, checks its Windows digital signature, and opens the installer. You need internet for this step. Enable Add Python to PATH in the installer.
6. After installation, rerun INSTALL_PYTHON_AND_START.bat if needed.

IMPORTANT: The Python Windows installer itself is NOT included in this ZIP. It must be downloaded using internet access. For fully offline installation, download the Windows 64-bit installer separately from https://www.python.org/downloads/windows/ and copy it to your USB drive alongside this ZIP.

This is development software. Do not use as the primary register for real transactions until the financial calculations, security and printing have been validated. Back up the local database regularly.
